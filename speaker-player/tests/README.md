# Tests

Run from this application's directory in PowerShell on Windows:

    .\test.ps1
    .\test.ps1 -Platform x86

The default checks compile and run TimingChecks, SequenceDataChecks,
PlaybackTests and ProcessTests. Fixtures are generated by the tests.
No music downloads, model, Python, Node, InpOut DLL or driver are needed.
The tests use Visual output and never open a speaker or ordinary audio backend.
Process checks create and cancel only their own child processes.

Results and temporary executables go to build/tests/x64/ or build/tests/x86/,
which is ignored by Git. Each folder has its own test-results.json. Counts in console
are the counts of that actual run; timed progress tests can vary slightly.

Optional diagram UI checks require an interactive Windows desktop:

    .\test.ps1 -IncludeVisualUi

These checks use offscreen windows and generated MIDI. They check selection,
DPI, note labels, rests and render PNGs without playing sound.

Optional pure Python MIDI export checks require Python 3.10+ and Mido:

    python -m pip install -r tests/requirements.txt
    python tests/TranscriptionChecks.py

Python is used only for these optional export tests. They do not import PyTorch,
load a model, decode user audio, or contact a transcription service.
