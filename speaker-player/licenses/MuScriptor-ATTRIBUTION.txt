Speaker Studio uses the direct transcription model API locally on CPU.
The application does not expose or bundle the MuScriptor web server or
download/authentication workflow. Local paths to the included weights are
passed explicitly; model downloads, uploads and account authentication are
not performed by the converter.

The model predicts note events and instrument groups. Conversion keeps
polyphonic notes and instrument tracks. MIDI velocity is fixed at 64 because
the model does not predict it. Padded model endings are clipped to the audio
duration; overlapping repeats of the same instrument/pitch are shortened
to the next attack. Original note timing is otherwise preserved, without
beat quantization or added bar padding.

Portable dependencies retain their individual notices in their .dist-info
directories. Python's license is runtime/transcription/LICENSE.txt.
PyTorch's licenses are in runtime/transcription/site-packages/
torch-2.8.0+cpu.dist-info/licenses. Headers, static libraries and tests were
excluded from the CPU runtime. The direct model path was tested with
Python 3.12.14, torch 2.8.0+cpu and NumPy 1.26.4; this does not assert full
compatibility with MuScriptor's separate web/CLI/beat-model package APIs.
