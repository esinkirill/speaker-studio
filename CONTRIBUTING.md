# Разработка Speaker Studio

Исходники приложения — C# 5 / .NET Framework 4. Команды выполняются в PowerShell из корня репозитория:

```powershell
.\speaker-player\build.ps1
.\speaker-player\test.ps1
```

- Воспроизведите ошибку на небольшом синтетическом MIDI/CSV; запишите ожидаемый и фактический результат.
- Исправляйте нужный модуль и добавляйте тест, который воспроизводит причину ошибки.
- Для `SequenceTiming` проверяйте длительность, паузы и повторные атаки; график, CSV и playback используют одну преобразованную последовательность.
- Для seek проверяйте переходы внутри ноты, тишины и при pause.
- Конвертер принимает события `pitch`, `start`, `end`, `program`, `instrument`, `is_drum`: время — в секундах, высота — MIDI note. Сохраняйте этот контракт при изменении экспорта.
- В pull request опишите изменение и команды проверки; для UI приложите снимок результата.

Назначение suites, optional проверки и отчёты описаны в [руководстве по тестам](speaker-player/tests/README.md).
Устройство приложения — в [разборе архитектуры](docs/ARCHITECTURE.md).
