# Руководство

## Первый запуск

Скачайте комплект с моделью и выполните `Prepare-Audio.cmd` по
[README](../README.md), либо соберите EXE из исходников. Добавьте
`examples/demo.csv` кнопкой **«Добавить треки»**
или перетащите файл в окно. Для знакомства выберите **«Диаграмма — без звука»**:
график и live console работают без InpOut и аудиоустройств.

## Библиотека

Поиск слева фильтрует добавленные записи по имени; список форматов ограничивает
результаты MIDI, CSV или аудио. **«Убрать из списка»** удаляет запись библиотеки,
сам файл остаётся. Список путей сохраняется в локальном `data/library.json`
рядом с EXE; настройки эффектов между отдельными запусками не сохраняются.
Для сохранения библиотеки запускайте приложение из папки с правом записи.

Для MIDI с несколькими музыкальными партиями появляется selector партии.
Выберите ведущий инструмент, если правило верхней активной ноты в смешанной
аранжировке добавляет бас/аккорды. При одной партии дополнительный selector скрыт.

## Воспроизведение и перемотка

**«Играть»**, **«Пауза»**, **«Стоп»** управляют текущим запуском.
Щелчок или перетаскивание маркера на дорожке выбирает место старта; slider под
дорожкой делает то же. В процессе проигрывания это seek; при pause позиция меняется,
но pause сохраняется. **«С начала»** возвращает marker к нулю.
Повтор проигрывает выбранный остаток, затем полный трек с начала.

MIDI представлен нотами piano roll, CSV — частотой во времени.
Live console показывает шаг, позицию, Hz, duration и pause.

## Тон и темп

Тон задаётся в полутонах: **−12** — октава ниже, **+12** — октава выше,
**0** — исходная высота. Например, 440 Hz после −12 становится примерно 220 Hz.
Параметр не меняет время.

Для темпа выберите **%** или **BPM**. 100% сохраняет время, 50% удваивает длину,
200% сокращает вдвое. BPM доступен, когда известен исходный темп; target/source
даёт коэффициент скорости. «Оригинал» возвращает исходный темп.
«Настучать» при известном исходном BPM задаёт целевой темп; при неизвестном
задаёт исходный BPM вручную, без автоматического определения по мелодии.

Исходный BPM берётся из MIDI tempo events или metadata. Для audio он отдельно
оценивается Essentia, если подготовлен runtime. При неизвестном BPM значение
120, использованное для записи MIDI clock, не считается доказанным BPM записи.
Переменная tempo map сохраняется; равномерная сетка для неё отключена.

## Ритм и переходы

Откройте **«Ритм и переходы…»**. Hover-подсказки объясняют формулы.

| Настройка | С чего начать |
| --- | --- |
| Разделение | 10 мс для короткой тишины между нотами |
| Ритм / сетка | «Исходный ритм» для сохранения MIDI timing; 1/16 при эксперименте с сеткой |
| Звук, % | 90% для звука с небольшим промежутком в клетке |
| Переход | 80 мс для сравнения с исходным 0 мс |
| Шаг кривой | 10 мс для первого сравнения; 5 мс увеличивает число переключений |

Для непрерывного glide выставьте разделение 0. Реальные REST и существующие
паузы не соединяются переходом. Кривая меняет высоту, а не тембр или напряжение.
Более мелкий шаг сам по себе не гарантирует лучшего звучания: короткие сегменты
зависят от Windows scheduling и аппаратного speaker.

## MIDI → CSV

Добавьте MIDI и выберите партию. **«Создать CSV»** записывает исходную выбранную
монофоническую последовательность с исходным timing, без эффектов плеера.
Чтобы записать выбранный тон, темп, разделение, сетку и glide, нажмите
**«Сохранить CSV»**: эта кнопка использует ту же преобразованную последовательность,
что playback и график. Результаты получают понятное имя, совпадения — числовой
suffix. Сохранённый CSV и его sidecar-файлы можно снова добавить в библиотеку.

## MP3/WAV → MIDI

В релизе 2.0.1 модель и CPU runtime уже вложены; FFmpeg и Essentia добавляет
`Prepare-Audio.cmd`. Подключение к своей сборке описано в [MODEL.md](MODEL.md).
Перейдите на вкладку **«MP3 → MIDI»**,
выберите audio и запустите конвертацию. Output создаётся автоматически в
`output/` рядом с EXE, с suffix «— MIDI» и уникальным именем. Результат добавляется
в библиотеку; затем выбирайте партию и создавайте CSV как выше.

CPU inference может занимать заметно больше времени, чем сама запись.
Отмена останавливает принадлежащий конвертеру процесс и его дочерние процессы.
Аудио не отправляется на внешний сервис. Для первого знакомства можно получить
MIDI внешним инструментом и сразу добавить готовый файл в плеер.

## Если нет звука

| Ситуация | Что проверить |
| --- | --- |
| Работает только график | Выбран visual output или отсутствует необязательный backend |
| Писк из монитора/колонок | Это audio preview / системный Beep; выберите физический speaker |
| Ошибка загрузки InpOut | Версию DLL, разрядность процесса, administrator и политику driver loading |
| Команда прошла, но корпус молчит | Подключение по manual, наличие speaker и аппаратного PIT/gate path |
| MP3 runtime недоступен | Дерево runtime/models/assets по DEPENDENCIES.md |
| CSV одной колонкой | Импорт с правильным delimiter по CSV_FORMAT.md |

Не переключайте провода при включённом питании и не используйте случайные pins.
Успешный вызов программы отдельно от результата на физическом speaker.
