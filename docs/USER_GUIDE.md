# От MIDI до звучащей мелодии

После [установки приложения](../README.md#скачать-и-запустить) можно начать
с готового MIDI или добавить запись на вкладке MP3 → MIDI. Дальше для обоих
вариантов получается одинаковый маршрут: выбрать партию, настроить звучание,
сохранить CSV.

## Выбрать голос

В MIDI часто одновременно звучат мелодия, бас и аккорды. Пищалка получает
одну частоту, поэтому сначала стоит выбрать инструмент с нужной линией.
Список партий появляется, когда в файле несколько музыкальных инструментов.

Начните с короткого узнаваемого фрагмента и выхода **«Колонки — предпросмотр»**.
Если вместо мелодии слышны бас или скачки между аккордами, попробуйте другую
партию. По умолчанию из её одновременно активных нот берётся верхняя.

MP3-конвертер сохраняет многоголосный MIDI и добавляет результат в библиотеку.
Подготовка конвертера и размещение файлов описаны в
[инструкции по модели](MODEL.md).

## Опустить тон

Тон задаётся в полутонах: **−12** опускает мелодию на октаву,
**−7** — на квинту, **0** оставляет исходную высоту. Например, 440 Hz после
−12 становится 220 Hz. Время при транспонировании сохраняется.

Удобно поставить маркер перед коротким фрагментом и сравнить два значения
на одном и том же месте. Маркер задаёт начало воспроизведения; его можно двигать
и во время звучания, и на паузе.

## Настроить темп

При известном исходном BPM можно задать целевой. Из 120 в 90 BPM получается
коэффициент скорости `90 / 120 = 0,75`: трек длится в 1,33 раза дольше.
Режим процентов даёт тот же контроль без известного BPM:
100% — исходная скорость, 50% — вдвое медленнее, 200% — вдвое быстрее.

Для MIDI темп берётся из tempo events; для аудио его оценивает Essentia.
Оценка может оказаться вдвое выше или ниже ожидаемой музыкальной доли.
Кнопка **«Настучать»** позволяет задать темп вручную: целевой, если исходный
уже известен, либо исходный, если данных о нём нет.

В файлах с переменным темпом сохраняется tempo map. Равномерная сетка
для них отключена, поскольку одной величины BPM недостаточно для всех долей.

## Сделать ноты разборчивее

В окне **«Ритм и переходы…»** настройки решают четыре задачи:

| Задача | Настройка | Отправная точка |
| --- | --- | --- |
| Разграничить соседние ноты | Разделение | 10 мс |
| Немного выровнять начало и конец нот | Подровнять — мягко | Сетка 1/16 |
| Ритмично прерывать удерживаемые ноты | Звук / тишина | Сетка 1/16, звук 90% |
| Плавно менять высоту между нотами | Переход | 80 мс, шаг кривой 10 мс, разделение 0 |

Разделение забирает время из звучания и переносит его в паузу. Например,
`200 мс звука + 0 мс паузы` превращается в `190 + 10`; темп сохраняется.

В режиме «Подровнять — мягко» границы нот перемещаются на половину расстояния
к ближайшей точке сетки. Для 120 BPM сетка 1/16 имеет шаг 125 мс:
четыре части на четверть. Метки **T** обозначают триольное деление.

«Звук / тишина» разбивает звучание внутри клеток: 90% времени клетка звучит,
10% молчит. Значение влияет на артикуляцию; напряжение на speaker остаётся
тем же.

Плавный переход соединяет соседние ноты, между которыми нет тишины.
Существующие паузы сохраняются. Мелкий шаг кривой создаёт больше коротких
сегментов; если на конкретном ПК переход становится неровным, попробуйте
шаг 20 или 50 мс.

Формулы сетки и переходов разобраны в
[разделе исследования об артикуляции](RESEARCH.md#артикуляция-без-растягивания-трека).

## Сохранить результат

**«Создать CSV»** записывает выбранную монофоническую партию с исходным
временем. **«Сохранить CSV»** сохраняет уже настроенные тон, темп, разделение,
сетку и переходы — ту последовательность, которую показывают график и плеер.

Для самостоятельной правки частот и пауз подходит Excel.
[Справочник CSV](CSV_FORMAT.md) объясняет столбцы и импорт с точкой с запятой.
Если рядом с треком есть файлы BPM и других параметров, переносите их вместе
с CSV: так сохраняются сведения о темпе и уже применённых эффектах.

## Библиотека и результаты конвертации

«Убрать из списка» удаляет запись библиотеки, сохраняя сам файл.
Библиотека хранится в `data/library.json` рядом с EXE. MP3-конвертация
сохраняет MIDI в `output/`; при совпадении имени добавляется номер.

Настройки звучания действуют в текущем запуске. Чтобы перенести настроенную
мелодию на другой ПК или открыть её позже, сохраните обработанный CSV.

## Если результат не тот

| Ситуация | Что сделать |
| --- | --- |
| Писк идёт из монитора | Выбрать «Пищалка материнской платы» вместо предпросмотра |
| Есть только график | Выбрать звуковой выход |
| Корпус молчит | Проверить наличие speaker и подключение к Speaker/Buzzer по руководству платы |
| InpOut не загружается | Запустить физический режим с правами administrator; проверить доступность драйвера в Windows |
| MP3 → MIDI не запускается | Выполнить `Prepare-Audio.cmd`; проверить [структуру runtime](MODEL.md) |
| CSV открылся одной колонкой | Выбрать разделитель по [инструкции для Excel](CSV_FORMAT.md#редактирование-в-excel) |
