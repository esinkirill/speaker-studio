# CSV: частота, длительность, пауза

После сведения MIDI к одной линии трек можно описать тремя числами:
какая частота звучит, как долго она звучит и сколько тишины следует за ней.
Этот формат удобно редактировать в Excel или создавать собственным скриптом.

```csv
frequency;duration;pause
440;200;10
494;200;10
0;100;0
523;300;50
```

| Столбец | Единицы | Значение |
| --- | --- | --- |
| frequency | Hz | Частота; 0 — тишина |
| duration | мс | Длительность частоты или тишины |
| pause | мс | Пауза после строки |

Заголовок обязателен. Все значения — целые неотрицательные числа до
`2 147 483 647`. Плеер принимает точку с запятой, запятую и tab;
экспорт использует `;`, удобный для русских региональных настроек Excel.

Общая длина трека равна `Σ(duration + pause)`. Пример выше длится 870 мс.
CSV уже содержит одну линию частот; выбрать другую партию исходного MIDI
по нему нельзя.

## Добавить промежутки без изменения темпа

Увеличение только `pause` удлиняет трек. Для артикуляции без замедления
нужно перенести время из `duration` в `pause`:

```text
440;200;0  →  440;190;10
```

Оба события занимают 200 мс. Настройка «Разделение» в приложении выполняет
такое перераспределение автоматически; подробнее —
[в руководстве по ритму](USER_GUIDE.md#сделать-ноты-разборчивее).

Число строк не определяет BPM. Одна нота может стать десятками строк после
плавного перехода или разбиения по сетке, сохранив ту же длительность.

## Редактирование в Excel

Если CSV оказался в одной колонке:

1. Выделить колонку.
2. Открыть **Данные → Текст по столбцам → С разделителями**.
3. Выбрать **точку с запятой**; для старого CSV с запятыми — запятую.

После правки сохранить именно CSV. Переименование XLSX в `.csv` не меняет
формат файла. Заголовок `frequency;duration;pause` должен сохраниться.

## Файлы рядом с треком

Миллисекунды задают время, но не содержат сведений о музыкальных долях.
Для BPM и дополнительных параметров приложение использует небольшие
текстовые файлы рядом с MIDI или CSV:

| Добавление к полному имени трека | Содержимое |
| --- | --- |
| `.bpm.txt` | BPM, соответствующий времени этого файла |
| `.bpm-varies.txt` | Признак переменного темпа |
| `.grid-phase.txt` | Смещение сетки, мс |
| `.audio-offset.txt` | Смещение относительно исходного аудио, секунды |
| `.processed.txt` | Признак уже применённых эффектов |

Для `demo.csv` файл темпа называется `demo.csv.bpm.txt`. После «Сохранить CSV»
в нём записывается BPM с учётом выбранной скорости.
Переносите эти файлы вместе с треком. Без них частоты всё равно проигрываются,
но сведения о темпе или обработанном экспорте теряются.

MP3-конвертер отдельно создаёт `<имя>.rhythm.json` с результатом анализа
ритма и `<имя>.transcription.json` с параметрами распознавания.
Их назначение описано в [интеграции модели](MODEL.md).

Чтение и экспорт CSV реализованы в
[SequenceData.cs](../speaker-player/src/SequenceData.cs).
