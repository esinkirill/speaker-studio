# CSV для одной частоты

CSV хранит последовательность времени для монофонического speaker.
Канонический разделитель — `;`, чтобы Excel с русскими региональными настройками
обычно открывал данные тремя столбцами. Parser также принимает `,` и tab.

```csv
frequency;duration;pause
440;200;10
494;200;10
0;100;0
523;300;50
```

| Столбец | Единицы | Значение |
| --- | --- | --- |
| frequency | Hz, целое неотрицательное | Частота; 0 обозначает тишину |
| duration | ms, целое неотрицательное | Продолжительность частоты или тишины |
| pause | ms, целое неотрицательное | Тишина после этой строки |

Заголовок обязателен; имена трёх колонок проверяются. Значения должны помещаться
в `Int32`. Аппаратный backend дополнительно ограничивает частоту диапазоном
делителя PIT; это не ограничение текстового CSV и не акустическая гарантия.

Общая длина: `Σ(duration + pause)`. Пример выше занимает 870 мс.
CSV не хранит velocity, инструменты, аккорды и исходные MIDI tracks.

## Пауза и BPM

Если вручную добавить 10 мс в каждую `pause`, не меняя `duration`, трек станет
длиннее. Если нужна артикуляция без замедления, сократите `duration` на 10 мс
и увеличьте `pause` на 10 мс. Параметр «Разделение» в приложении делает именно
такую переразметку внутри доступного времени.

Число строк не является ни BPM, ни количеством исходных нот: glide и сетка могут
создать несколько строк из одной ноты. Короткая запись может содержать много строк,
а длинная с удерживаемыми нотами — мало.

## Excel

Если всё попало в одну колонку: выделите её → **Данные → Текст по столбцам →
С разделителями → точка с запятой**. Для старого файла с запятыми выберите запятую.
Редактируйте колонку `pause`, сохраните как CSV и повторно откройте в приложении.
Не сохраняйте XLSX под расширением `.csv`.

## Metadata

Рядом с MIDI/CSV приложение читает или сохраняет отдельные текстовые sidecar-файлы:

| Suffix после полного имени файла | Содержимое |
| --- | --- |
| `.bpm.txt` | Известный исходный BPM |
| `.bpm-varies.txt` | Признак переменного темпа |
| `.grid-phase.txt` | Фаза музыкальной сетки, ms |
| `.audio-offset.txt` | Смещение относительно исходного audio, seconds |
| `.processed.txt` | Признак уже применённых эффектов экспорта |

Например, для `demo.csv` BPM-файл называется `demo.csv.bpm.txt`.
JSON используется отдельно для отчётов анализа и transcription:
`<stem>.rhythm.json` и `<stem>.transcription.json`.
Переносите sidecar-файлы вместе с треком, если нужны эти сведения.
Без него CSV по-прежнему проигрывается, но миллисекунды сами по себе не доказывают
известный музыкальный BPM. Признак обработанного экспорта нужен, чтобы эффекты
не применялись повторно при загрузке.

Реализация: [SequenceData.cs](../speaker-player/src/SequenceData.cs),
[RhythmSettings.cs](../speaker-player/src/RhythmSettings.cs).
